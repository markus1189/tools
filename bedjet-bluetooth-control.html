Memories

Shutdown log

Every switch to standby. Unexpected: more than a minute was left and Off wasn't pressed in this app (the unit's own remote counts as unexpected). The reason byte is undocumented; the count per code shows patterns.

Protocol probe

Read-only: sends only bio queries (41 id tag) and records which characteristic answers and what this firmware returns, to settle 2005 vs 2006 and spot firmware differences.
